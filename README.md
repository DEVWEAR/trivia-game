# Patient Experience — Complaint Training

A **public demo-only** complaint-ticket practice interface with 34 columns modeled on screenshots of a complaint log.

- Fictional sample data only. Never enter real patient information.
- No server, analytics, localStorage or persistent storage.
- Data remains in the active browser tab until cleared or closed.
- Demo CSV export and tab-separated copy.
- The original trivia game is retained in branch `backup-trivia-before-complaints-2026-11-16`.
- Not an authorized hospital system.
